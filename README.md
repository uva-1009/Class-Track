# Class Track

Class Track is a Python-based desktop application designed to automate student attendance tracking, streamline record management, and generate automated reports for educators.

##  Tech Stack
* **Language:** Python
* **GUI Framework:** Tkinter
* **Database:** MySQL

##  Key Features
* **Automated Attendance:** Simplifies the tracking process for daily student attendance.
* **Record Management:** Securely stores and edits student logs.
* **Report Generation:** Generates automated summaries and tracking sheets.
